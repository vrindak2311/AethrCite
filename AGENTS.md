## Project Summary
AethrCite is a comprehensive code plagiarism detection web application. It features user authentication, multi-format file uploads (PDF, Image, Text), token-based plagiarism analysis, and AI-powered rewriting suggestions to help developers maintain code originality.

## Tech Stack
- **Frontend**: Vanilla HTML5, CSS3, JavaScript (ES6+)
- **Storage**: Browser `localStorage` for authentication and history tracking
- **Design**: Dark theme with purple and neon accents, mobile-responsive layouts, and custom CSS animations.

## Architecture
- Single-page application (SPA) style routing handled by JavaScript state management.
- `index.html`: Main entry point containing all view templates.
- `styles.css`: Centralized styling with CSS variables for the dark theme.
- `app.js`: Main logic for routing, authentication, plagiarism detection, and history management.

## User Preferences
- Pure Vanilla JS implementation (No frameworks).
- Dark theme only (No blue colors).
- Modern, distinctive aesthetics with smooth transitions.

## Project Guidelines
- Use CSS variables for colors.
- Maintain a clean, modular JavaScript structure.
- Ensure high visual accuracy and responsiveness.

## Common Patterns
- View switching via `display: none/block`.
- LocalStorage for persistent user data.
- Event-driven UI updates.
